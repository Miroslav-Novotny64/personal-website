Moderní PWA implementace klasické společenské dedukční hry „Impostor“. Nechtělo se mi platit za aplikaci, tak jsem si postavil vlastní.

## Technologie

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS (Vlastní krémové a žluté téma)
- **Animace:** Framer Motion (3D otáčení karet a mikro-interakce)
- **Ikony:** Lucide React
- **Stav:** React Hooks + LocalStorage Persistence

## Funkce

- **Dark Mode:** Plná podpora tmavého režimu s přirozeně působícím přepínačem.
- **PWA:** Možnost instalace na iOS a Android pro plnohodnotný zážitek na celé obrazovce.
- **Perzistentní stav:** Seznam hráčů a výběr kategorií zůstává uložen mezi relacemi.
- **Modularita:** Snadno rozšiřitelný systém kategorií.
- **Strategické nápovědy:** Unikátní nápovědy pro impostora pro udržení vyváženosti hry.
